# S2 记忆语义实施契约

按属性目录、写入语义、完整路径验收三个任务串行交付。基于 I1–I4 规格，沿用身份 v1 编码、命令幂等、单 durable Worker 和来源撤回机制。

## 属性目录

管理员在 tenant/workspace 内注册 predicate、single/multi 与 required_context。属性不可变；相同定义可重放，不同定义拒绝。已有身份（包括未发布和已删除身份）的 predicate 不允许被目录接管，防止重解释旧数据。旧 fact_key 不绑定新目录。目录属性禁止通过旧 identified/capture 入口写入。

本切片只在新数据库创建可选目录表，启动不 ALTER 旧库。缺表的旧库继续运行原功能，新目录/语义功能不可用；现有身份安装命令不安装 S2。旧数据迁移/导入需独立设计与验收。

## 显式语义写入

新增语义入口接受 identity（可省略以保留歧义输入）、原始 content、assert/update/supplement/negate/propose/ambiguous 操作、值及其逐字原文 quote 和 UTF-8 半开区间。值采用精确字符串等价，不自动折叠名字、同义词或 Unicode。原文区间证明溯源，不证明值或操作分类正确；调用方对显式分类负责。此切片不把自由文本模型判定作为覆盖授权。

- assert：无当前值时建立事实；同值幂等；与单值当前事实不同则保留冲突证据，不覆盖。
- update：只允许单值，必须带当前 expected_version，追加版本。
- supplement：只允许多值，集合并集；重复值不制造版本。每个成员保留其原始来源与字节区间。
- negate/propose/ambiguous 或缺失身份：独立未归一化来源资产，标明具体状态，不绑定当前身份，不改当前事实。
- 单值输入包含多个不同值：保留为 conflict。未知属性或缺少必需条件：拒绝，不猜测归一化。

新语义写入必须给 expected_version（0 表示尚未发布）；确定事实在服务接收与 Worker 发布时双重校验。独立未归一化证据不更新建议身份，输入版本不作为该身份的更新条件。并发请求最多一个发布，另一个 superseded；重试复用持久任务，不另起队列。来源、幂等响应、资产和任务同事务创建。

## 发布及检索

确定事实继续使用既有身份资产；不确定证据使用无 fact_key、无身份的独立 memory 资产。语义 chunk 标记 parser、值、状态、原始来源与页外 UTF-8 范围；search/resolve 明确显示 normalization_status，精确身份检索只返回绑定的当前事实。

多值追加沿用既有整版本发布，当前版本依赖本次操作来源；撤回本次操作来源使整版退出读取，不自动回退历史。撤回较早成员来源同样使整个快照退出候选及读取，保持整版本可见性。保留的成员不能重新赋予新来源；更新/补充时不携带已撤回成员。若当前快照的发布来源本身撤回，按既有清理移除该版 chunk，后续写入须重新提供事实，不从历史自动补回。此保守规则不代表多来源独立资产发布，也不声称撤回可自动恢复上一版。

语义资产不能通过通用 restore 绕过写入规则；需要新的显式语义写入和有效来源。历史版本和历史 locator 不改写。

## 验收

公共库 API 和 HTTP → job → keyword/vector/resolve 路径覆盖：目录权限/隔离/旧库、单值重复与更新、集合补充、冲突/否定/提议/歧义、同名不同主体/不同条件/不同 workspace、并发版本、中文/emoji/组合字符、越界与伪造 quote、来源撤回、重试与重启、已登记属性旧入口拒绝。固定模型仅证明工程契约，不声称语义理解质量。
