# 证据包

**简体中文** · [English](evidence-bundle.md)

## 范围

本契约定义从记忆、知识、Learning 和显式启用的私有会话轮次只读组装上下文的规则。Skill 包和 Run 轨迹各有自己的读取契约。`Service::evidence_bundle`、HTTP `POST /v1/context` 和 MCP `context_bundle` 使用同一请求和响应。Search/resolve 保留独立契约。Guidance 仍属外部证据，无独立发布生命周期。按 AGENTS.md 的约束，当前面向新建数据库。

工程覆盖与 Agent 效果分别验收。夹具只验证测试框架行为。在运行环境、来源绑定和任何必要的供应商、数据或费用授权核实前，真实模型运行标为 **NOT_RUN**。

## 召回与权威校验

记忆、普通知识和 Learning 各用独立的当前分块候选池。在应用分路候选上限和原生向量 top-k 前，核对类型、作用域、精确身份与完整来源可见性。所有启用的内容检索路由共用一次查询向量化。关键词使用既有的查询全部词项匹配，混合使用确定性的 RRF60。每条路由每分支最多 100 个候选，显式返回候选数范围 1–100。原生内容检索使用原始分块。Search/resolve 的既有分支仍可用。

可选精确记忆身份只约束记忆，包括具有有效来源的同身份冲突证据。历史内容条目版本不会成为当前检索候选。会话引用仍保留归档时实际使用的精确历史版本。

日常上下文的 memory 路由也召回已归纳的事实主题。普通问句复用[长期记忆词项召回](memory-consolidation.md#统一召回)，取最多 32 个查询词项并扫描工作区内最多 512 条事实，返回 `scanned` 和 `scan_exhausted`。提供 `memory_identity` 时按精确身份读取，跳过该扫描。归纳主题优先使用 memory 路由候选名额，剩余名额供原始分块使用。已召回的归纳主题会排除同一完整身份的原始分块，冲突、未知或预算省略时也适用。其他身份仍可参与召回。词项查找独立于原生检索模式。最终授权快照读取各主题的最新版本，核对全部来源，并确认用于匹配的来源仍属于该版本。

会话默认关闭。任何模型 I/O 前检查实时 writer 或更高权限。关键词、向量和混合检索
限定在 workspace 和逻辑 key 对应的私有 AnySeek 集合。只有来源、归档引用及传递
Learning 支持仍可见的已归档轮次才进入候选。按 turn ID 去重，渲染前再次复核可见性。
`scanned` 为有效目录候选数。关键词覆盖完整问答。向量只表示问题和回答各自开头的
4096 UTF-8 字节，并在字符边界截断。只出现在尾部的语义不进入向量投影。

向量化及原生 I/O 结束后，在新的已授权关系快照中重建全部返回候选，并在快照仍打开时渲染。提交再次核对实时角色。快照之前撤回的证据在异步清理前即不可见。快照可见性不代表事实为真，也不保证与快照之后提交的撤回线性一致。

## 类型化来源与适用性

内容引用包含分块、内容条目及版本、原始来源及其版本、版本根来源事件和不可变定位符。三类版本或来源概念各自独立。会话来源是带类型的真实 (session_id, turn_id, source_event_id) 元组，保留归档引用，不虚构分块。引用 ID 包含会话与轮次 ID。

`as_of_ms` 指定业务时点（Unix 毫秒，默认当前时间）。`long_term_memory` 来源包含 `memory_id`、`version`、`as_of_ms`、`effective_from_ms`、该时点的 `state`、记录结论变化的 `timeline` 和 `citations`。每条引用含 `source_event_id`、事实生效时点 `effective_at_ms`，以及含原文引文与 UTF-8 半开字节区间的 `statement`。无日期基线和 `unknown` 的 `effective_from_ms` 为 `null`。`current` 提供单值，`conflicting` 和 `unknown` 无选定值。无可见匹配主题时不返回归纳条目。词项命中标为 `unverified`，调用方提供精确身份时标为 `caller_identity_exact_match`。

控制台用 writer 以上权限重新读取来源事件，核对原文引文与字节区间后高亮。Reader 可按固定记忆版本重新核验已发布的引文。每次打开均检查当前来源权限与可见性。

Reader 只可读取 Learning 已发布的 statement/why、精确条件及脱敏支持标识与区间。原始问答和引用原文要求 writer 权限及该私有会话逻辑 key 的所有权。条件同时保留于正文、条目元数据和引用来源。按调用方上下文精确匹配每个字符串条件，`caller_context_exact_match` 只代表调用方提供了这些字符串。否则适用性明确为 `unverified`。模型不解释、扩大或推断适用条件。

当前归档 API 的 `used_evidence` 只接受 chunk/entity/relation。内容引用可映射为精确分块引用，会话轮次引用无法原样写回。响应、保留会话块和 API 文档明确披露此限制。调用方不能伪造分块 ID 或声称归档覆盖完整。
归纳事实引用带 `unsupported_long_term_memory_reference` 标记。服务端 Run 准备在记录快照或失败事件前拒绝 `as_of_ms`。带日期的记忆查询使用独立上下文入口。

## 冲突与预算契约

仅合并类型和位置都相同的证据，保留关键词和向量来源。不同位置或版本即使正文相同，也不按相似度去重。只有精确的显式记忆身份，且属性登记为单值、语义值为 confirmed/conflict 时，才进入确定性冲突分组。不会推断多值事实、不同条件、否定、提议、歧义或非结构化文本的冲突。检查范围限于召回候选。普通记忆、文档和 Learning 文本矛盾标为 `not_assessed`，并未认证不存在冲突。

每组冲突是不可拆分的渲染单位，包含已召回的所有候选及警告。预算不足则整组省略并报告，不能在检测到冲突后只展示一方。
归纳事实也按主题整块保留结论、时间线及所有引用。业务时点冲突时，保留的主题列在 `conflicts`，因预算省略的主题计入 `omitted_conflict_groups`。其他时点的冲突随保留主题的时间线返回。

`budget` 和每条路由的 `max_bytes` 均按实际 UTF-8 字节计算。默认总计 4000 字节，每条启用路由 20 个候选和 4000 字节。这些是中性的上限，不是学习得到的质量权重或预留比例。按记忆、知识、Learning、会话稳定轮询，超大单位被跳过，后面较小单位仍可放入。标题、条件、来源、引用标记、冲突警告和分隔符均计费。保留完整块，不切断 Unicode 字符、不产生孤立引用、不省略所选块的警告。`rendered_context` 外的响应 JSON 不占上下文预算。

## 独立 Agent 效果证据

`evals/agent` 数据、`evals/agent/runner.py` 与 `evals/agent/local_chat.py` 使用独立编写的合成用例。四个分组共用模型、提示词、工具权限、模型调用和上下文预算，分别为无记忆、简化混合检索（关闭摘要和图）、EvidenceBundle 及明确不可部署的金标准诊断。有界模型/工具循环保存原始操作、观察、最终答案、引用、错误、分配任务分母、Token 用量与延迟。未知费用保留为未知。固定合成标签不会传给非金标准分组。

通用本地 JSON chat 处理独立实现，避免旧本地模型服务依赖图提取的专用 JSON 分发。确定性夹具只提供工程证据。单次真实回答模型试点或启发式字符串匹配不能证明可复现的 Agent 收益。须有配对重复结果、独立审阅的引用支持和明确成本/延迟证据。当前实现不意味着付费供应商调用、模型下载或私有数据传输。
