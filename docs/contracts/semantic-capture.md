# 受控对话提取

**简体中文** · [English](semantic-capture.en.md)

调用方显式提供原文与允许目标，模型只能在该范围内提议；确定性规则见
[记忆身份与语义](memory.md)。会话反馈学习见 [Improve / Learning](learning.zh-CN.md)。

## 契约

- 库 API 与 POST /v1/captures/semantic。调用方提交不可变原文 content 和最多 20 个允许的完整 identity 目标；目标属性必须来自当前 workspace 目录，条件完整。targets 可以为空，此时只能产出未归一化证据。
- 模型仅返回目标索引（或 null）、operation、带原文 UTF-8 字节区间的 statements。不能返回身份、租户、批准或发布字段；未知字段/越界/重复目标/伪造引用导致整批失败。总计最多 20 个候选、32 个 statement；原文最多 64 KiB。
- 提取是模型判断，不证明事实真假。目标稳定 ID 和适用条件由调用方给出，不自动解析别名。对话中提议、否定、歧义归入未归一化；不同的单值断言另存为冲突证据。若模型仍返回 update，保留引用为 ambiguous。显式确认通过记忆写入接口更新单值。长期记忆归纳通过其独立入口按证据计算结论。
- 受理事务读取全部目标的当前发布版本并随任务保存，可选的 expected_version 用作额外前置条件。任一显式版本过期即拒绝且不创建来源或任务。受理后，确定性候选在记忆语义路由时检查所用目标版本；计划保存后只复核实际路由到的记忆条目，包含 duplicate 结果的版本与当前可见性，不持续锁定未使用的 targets 或未归一化证据中的 suggested_identity。确定性 assert 路由为 conflict 前仍检查目标版本，之后独立发布证据；不确定候选不更新建议身份。实际确定事实的版本竞争使整批 superseded。
- 使用同一个记忆语义路由函数，实现重复不增版本、多值追加和冲突保留。每个候选独立记录路由结果；所有非重复结果在一个关系事务中发布，任何错误都不部分发布。
- 在原有串行 durable worker 内提取；模型/分词工作在事务外。路由计划在 embedding 前持久化，重试复用已保存的候选/目标/来源，不重新分类。进程在模型返回但计划提交前退出可能重新请求模型；不保证供应商调用恰好一次。
- 当前来源与集合成员来源在每次恢复和最终提交前复核，沿用记忆语义整快照撤回。locator 保留原始引用和来源；新增 extraction 元数据 semantic-capture:v2 与模型名称，不覆盖已有成员来源。
- 不增加 worker、自动调度、重试循环、硬取消保证或数据库升级。失败、取消、权限撤销、重启、搜索与撤回沿用现有治理。

精确运行结果统一见 [VALIDATION](../VALIDATION.md)；模型桩只验证工程契约，不证明真实模型分类质量。

控制台用证据 ID 和来源展示独立证据。固定引用继续带内部资产版本，长期记忆的结论版本和显式发布的版本校验可继续使用。
