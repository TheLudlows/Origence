## 剩余工作与验收

### A1 组别、模型和协议确认

- [ ] 确认文本赛道、类别、模型限制、当期输入/超时/配额；登记需要主办方确认的问题。
- [ ] 冻结 embedding/profile/维度、抽取模型、提示词、分块、组件开关；未启用组件也明确记录。
- [ ] 真实模型完成 Add → Search，验证鉴权、维度、模型错误和 profile 隔离；更换 embedding 使用新评测库重新生成向量。
- [ ] embedding 与抽取目前共用 Base URL/API Key；若需不同供应商，明确网关或拆分配置并验证，聊天接口不能代替 embeddings。
- [ ] 对照 [输入边界](API.md#aml-http-协议)：每批最多 256 条、正文合计 1,000,000 UTF-8 字节、query 4000 字节、top_k 1–100；核对角色、时间戳及 Add 等待/重试规则，不能靠静默截断兼容。

**通过条件**：申报配置能复现，真实请求完整写入、立即检索、跨用户隔离；模型或协议失败明确可见，不无提示改用另一方法。

### B1 持续容量与恢复

- [ ] 使用独立实例、数据目录和凭据，保持单宿主/单 Worker；覆盖预计 Full 时长，并测多用户增长与写入/查询交替。
- [ ] 记录 Add 全流程、排队及 Search 的 p50/p95/p99、失败率、模型调用/token、峰值内存、磁盘增长和恢复时间；保留冷启动及失败请求。
- [ ] 验证模型限流/不可用、连接中断、网关超时与同请求重试；分别检查进程、存储、Worker、模型，ready 不代表模型正常。
- [ ] 验证压实中断、磁盘不足后的恢复，测维护额外空间；再定位冷启动尾部，不提前引入多 Worker 或自动维护周期。
- [ ] 按 embedding、生成/重排、主机/磁盘/带宽估算费用与额度，计入重试；幂等不保证供应商只计费一次。

**通过条件**：在声明负载下完整运行并恢复，排队、磁盘、额度和超时边界明确。现有单轮实验不作为生产 SLO。

### B2 评测数据清理

- [ ] 私有评测数据只用于获准运行，不训练、分析、分享或进入公开逐题归档；日志不包含正文、问题、候选、模型响应或密钥。
- [ ] 登记 SQLite/WAL、向量、图、Blob、缓存、临时文件、日志、备份、快照及供应商保留设置，明确到期时间。
- [ ] 以合成数据演练专用实例整体退役，逐项验证副本和恢复通道不可读；保护业务库及历史公开工件。

**通过条件**：按 [退役步骤](AML_DRILL.md#退役与清理执行顺序) 留下脱敏清理证据。墓碑、cleanup 或目录删除不证明介质物理擦除；不可控制的保留边界单独记录。

### B3 冻结、Smoke、Full 与审核

- [ ] 准备系统/团队/联系人/类别、仓库与许可证、引用及方法变更说明。
- [ ] 固定 commit、构建/镜像摘要、模型和全部检索配置；材料不含凭据。
- [ ] 最后接入公网 HTTPS，提供 Add/Search/health、鉴权与受控凭据交付，以及容量、超时、限流和费用声明；申请平台 AML Key。
- [ ] 本地协议回归 → 官方 Smoke → Full → 审核；记录对应版本与允许保留的 Run/Job 状态，Full 受理后冻结实现、模型和配置。

**通过条件**：完整 Full 和官方审核均完成才标为榜单成绩；异常走复核，不根据私有题现场修改实现。公开仓库未提供完整离线 Smoke runner，运行方式见 [本地演练](AML_DRILL.md)。

## 提分研究与执行顺序

**本轮本地实验已结束；产品 S2/S3 与 S4 工程实现已交付，真实 Agent 效果仍为 NOT_RUN。** 以下是再次启动参榜准备或新质量研究时的依赖顺序，不是仍在执行的实验队列。未完成项及启动条件统一见[后续验收](superpowers/plans/2026-10-09-next-stage-roadmap.md#后续验收及启动条件)；A1/B1/B2/B3 仍是正式提交前的门槛。

按用户要求先做本地验证，服务器、域名及官方 Smoke/Full 后置；正式组别/模型未定不阻塞本地研究，但正式冻结前必须完成 A1。没有将旧日期安排继续当作交付承诺。

1. 补 B1 本地故障/持续容量和 B2 清理演练；正式配置确定后重跑相应验收。
2. 独立复核标签并冻结新留出集，研究时间、更新、多跳、多语言、无答案和增量可见性；当前已观察题仅作回归。
3. 同候选、同预算比较证据去重/邻接、关键词融合、重排及摘要/图；记录片段和来源覆盖、可答漏召回、错误回答/拒答、成本与延迟。没有稳定收益的组件继续留实验层。
4. A1/B1/B2 通过后冻结 B3，接入官方评测；无需等待全部提分方向完成或完整产品 P1。

质量实验登记数据来源/许可、划分、hash、模型、代码与提示词；金标准不进入可部署检索，留出题不用于调参。回答/裁判实验仅为本地代理指标，同模型复核不视为独立人工验证。研究依据见 [阶段决策](AML_RETRIEVAL_DECISION.md)，最新比较见 [同预算报告](../evals/aml/budget-v1/README.md)。

## 与产品的关系

协议适配复用产品 Service、来源、权限、持久 Worker 和存储；离线压实已是共享能力，恢复/长历史验证也覆盖共享路径。AML DTO、确定性 ID 与等待/响应仅留 API 适配层；通用 MessageBatch、所属授权、命令回执与实时发布状态可由非 AML 库调用方复用。路由默认关闭，受信 root key 能力必须显式授予。S2 语义规则、S3 反馈学习、S4 Agent 效果继续按产品路线推进；代码/多模态、完整有效时间、分布式和 SaaS 暂不作为首轮前置。

实现 PR 关联任务编号，遵守 [AGENTS](../AGENTS.md)，记录代码 SHA、公开库及真实 HTTP 链路验收和剩余限制；行为变更同步 API/OPERATIONS，进度与证据同步 STATUS/VALIDATION。历史报告及分数保持不变。
