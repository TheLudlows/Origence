## 失败与后续决策

- 原 24 题/12 篇 keyword 种子同代码复跑为 63.64%，错误 0、无答案误召回 0；固定八条失败为 retrieval-15 至 retrieval-22，见 [失败问句与冻结 hash](legacy-seed-failures.json)。它与本轮 36 篇/300 题分布不同，分数差不能解释为版本回退。
- keyword 仅命中精确编号问题。`keyword_hits` 要求查询分词是文档词集合的子集，自然问句中的疑问词与同义表达会阻断召回；后续优先以开发集验证中文查询解析与 FTS/BM25，保留留出集用于最终验收。
- vector/hybrid 的无答案题全部返回候选。检索候选不是可信答案；需要单独校准拒答/证据门槛并验证，不在这次看到留出结果后补阈值抬分。
- 摘要/图独立增益见 [逐题配对变化](paired-deltas.json)。仅据当前抽取器和当前冻结集决定是否启用，不能从某组低增益推出图谱对所有任务无价值。
- 本轮 36 篇规模没有 ANN 必要性的证据；暂不引入 ANN。重排仅在扩大困难候选集和运行预算后另行实验，当前不预先加入。
- 全量未命中、预算遗漏与无答案误召回见 [失败清单](failure-analysis.json)；真实生成图/摘要保留原始输出，没有按效果分数修补。
