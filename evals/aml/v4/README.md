# AML 成对反例 v4（尚未运行）

2026-10-11 冻结 32 题/16 对、32 个独立用户、64 个 session、188 条短消息。开发与新主题各 8 对；每对问题完全相同，正例包含完整证据，负例只移除最后一条必要事实，保留相似干扰。类别为属性、主体、事件时间、合取条件、严格数值边界、多跳、多语言计算和嵌入指令。

[corpus.json](corpus.json) 供 Add/Search；[rubrics.json](rubrics.json) 只供离线评分，绝不能进入检索/重排/核验提示词。多跳与计算允许由完整来源推导，不要求答案逐字出现。数值边界、条件、身份与附加陈述必须语义核查，不能沿用旧的短语命中即通过。金标准来源使用原消息位置，仍要求原文与完整用户隔离。

[freeze.json](freeze.json) 记录当前数据/标签哈希，模型与检索调用为零。执行配置尚未冻结，未取得任何质量分数。首次模型调用前应另冻结 prompt、token/请求预算、模型及评分方法。开发数据用于调参，新主题只作冻结配置验收；不得把本文集和已观察 v2/v3 混称未见测试。
