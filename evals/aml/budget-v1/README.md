# AML 同预算比较 v1

执行前冻结见 [freeze.json](freeze.json)。本轮依次完成长消息定位校验、配置冻结、v4 32 题与公开 LongMemEval 32 题比较，再作接入决策。三臂为原文 vector、原聊天重排、固定本地 BGE；均无扩展/摘要/图。

共同 top-100 原始召回按顺序最多取 40 条、8,000 个参考 tokenizer token、32,000 UTF-8 bytes；最终证据最多 5 条、2,000 参考 token、9,000 bytes。预算计算含序列化证据元数据；达到上限停止取后续条目，不截断原文。参考 token 使用已固定 BGE tokenizer，不冒称 Qwen token；供应商实际用量另记。限额是相同上限，并不强行填满各臂上下文。BGE 每对上限从历史实验的 512 显式改为 1,024，不截断；超限作为错误。

固定原 Answer 提示词；public 另提供问题日期。金标准仅进入离线评分。匿名化臂顺序的同 Qwen 裁判检查实体、时间、合取条件、严格边界、计算/多跳与引用支持。v4 另要求所有必要消息完整引用；public 只有会话级标签，所以只报告 session recall，不能宣称完整证据 recall。运行/裁判错误保留在分母。没有独立人工复核，不是官方 AML 或完整 LongMemEval 成绩。

公开 1,524 批/15,685 条消息均保留，32 个问题各自独立用户，绝不合并共享历史的用户语料；共享会话仅用于分组统计，10 个连通分组大小为 15、8、2、1、1、1、1、1、1、1。数据日期未指定时区，统一按 UTC 编码是明确适配约定，不宣称真实时区。v4 按 16 个题对分组，开发/新主题分别单列。原冻结语料和历史工件不改写。

阶段：retrieve → prepare → rank(chat/bge) → answer(vector/chat/bge) → grade。每阶段独占创建压缩报告，失败保留且不自动重试；上游工件及冻结输入校验 SHA-256。预定最多 320 次聊天调用，每个独立阶段最多 60 次、单次 60 秒、temperature=0、无 thinking、最多 2,048 输出 token。服务/域名/官方 Smoke 后置。

接入门槛在运行前写入 freeze：全部成对安全用例通过、每个划分的受支持成功率不低于聊天重排、无来源/执行错误、重排额外延迟 p95 ≤3秒；本地 BGE allocator 峰值≤3GiB（不代表整机显存/内存）。小样本、宽区间与独立人工复核缺失仍限制生产结论。
